# Multimedia Information Retrieval System (MIRS)

## Overview

Multimedia Information Retrieval System (MIRS) is a Python and Streamlit-based application that retrieves similar multimedia content using AI techniques. It supports image retrieval and text-based search through an interactive user interface.

## Features

* Image similarity search
* Text-based retrieval
* User-friendly Streamlit interface
* Fast and accurate retrieval using deep learning
* Audio and Video features
## Technologies Used

* Python
* Streamlit
* TensorFlow
* MobileNetV2
* TF-IDF

## How to Run

1. Install the required packages:

   
   pip install -r requirements.txt
   
2. Run the application:

   
   streamlit run app.py
